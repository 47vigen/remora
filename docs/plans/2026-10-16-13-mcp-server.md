# MCP Server Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let Claude Code, or any MCP client, operate remora through eleven task-shaped tools served at `/mcp` on
the existing listener and over stdio by `remora mcp`, with exactly the authentication, validation and errors of the
management API.

**Architecture:** `internal/mcp` builds one go-sdk server whose tools call only the generated management client.
For `/mcp` that client serves each call in process with the `/api` handler and the caller's own `Authorization`, so
the API authenticates every tool call again; for `remora mcp` it is the CLI's network client. Outside the package,
only `plan_hash` is added to config plan/apply, checked inside the apply transaction.

**Tech Stack:** Go 1.27, `github.com/modelcontextprotocol/go-sdk` **v1.8.0** (latest, `go list -m -versions`
2026-10-16), oapi-codegen, `net/http/httptest`, `crypto/sha256`, Docker Compose e2e with the fakes image.

**Spec:** `docs/specs/2026-10-16-quota-routing-mcp-design.md`, section "3. MCP server", plus Goals, Non-goals and
Delivery. Evidence: `docs/research/2026-10-16-mcp.md`; where it differs, the spec wins (`plan_hash` is server-side).

**Depends on:** plans 11 (`docs/plans/2026-10-16-11-account-quota.md`) and 12
(`docs/plans/2026-10-16-12-routing-strategies.md`), **both merged into `main` first**; their endpoints are used
through the regenerated client only. Before Task 1, replace the assumed ids below with those in the merged
`api/openapi.yaml`.

## Global Constraints

- Streamable HTTP at `/mcp` on the existing listener, **stateless, JSON responses**, official go-sdk.
- Authenticated by the existing API tokens (`rmt_…`) as `Authorization: Bearer`, through the existing auth service.
  **No cookies, no OAuth, no scopes.**
- Every tool calls the management API through the generated client, never a store, port or handler method. The
  in-process client forwards **the caller's** `Authorization` and nothing else: no header means a 401, never a
  server credential.
- Every tool carries `readOnlyHint` / `destructiveHint` annotations.
- Providers, aliases, keys, alias strategies and account strategies are written **only** through
  `remora_config_plan` + `remora_config_apply`. `prune` defaults to **false** in MCP (the API default stays `true`),
  so the tools always send it explicitly.
- Not over MCP (spec non-goals): resources, prompts, sampling, elicitation, OAuth, scopes, a chat tool, generated
  tools, API token create/delete, the admin password.
- No engine name in a tool name, description or result. `api/openapi.yaml` changes only for `plan_hash`.
- Tests before code. `go test -race ./...` and `golangci-lint run` stay green after every task.
- Conventional Commits with scopes. CHANGELOG is release-please's, written from the `feat(...)` commits.
- Branch `mcp-server`, one PR to `main`.

## Review Focus

1. **A partial document naming one alias whose members reference stored providers absent from the document.** With
   `prune: false` it must plan exactly one alias change and delete nothing. Test: Task 1,
   `TestPlanPartialAliasAgainstStoredProviders`.
2. **The store changes between plan and apply** (the console, a second agent). Apply must change nothing and answer the fresh plan and hash. Test: Task 1, `TestApplyConfigPlanHashMismatch`, and Task 4,
   `TestConfigApplyStaleHash`.
3. **A `/mcp` request with only the console's session cookie** (a browser, CSRF). It must be 401. Test: Task 2, `TestHandlerRefusesCookie`.
4. **remora behind a reverse proxy on the same host** (request from `127.0.0.1` with `Host: remora.example`). The
   go-sdk's DNS-rebinding guard would 403 it; with `DisableLocalhostProtection` and a valid token it must be 200.
   Test: Task 2, `TestHandlerBehindLocalProxy`.
5. **A log entry with a multi-megabyte body.** Claude Code caps a tool result near 25k tokens; `remora_logs` must
   truncate each body to 4096 bytes and say so. Test: Task 3, `TestLogsTruncatesBodies`.

## go-sdk v1.8.0 facts this plan relies on

- `AddTool[In, Out any]` infers both schemas (`jsonschema:"…"` tags describe fields; `Out = any` omits the output
  schema); a handler `error` becomes `isError: true` (`server.go:405-432,603`). `ToolAnnotations{ReadOnlyHint bool;
  DestructiveHint *bool; IdempotentHint bool; OpenWorldHint *bool}`.
- `NewStreamableHTTPHandler` options `Stateless`, `JSONResponse`, `DisableLocalhostProtection`
  (`streamable.go:128-185,231`); only a stateless server accepts protocol 2026-07-28.
- `req.Extra.Header` is the HTTP request's header under Streamable HTTP, nil under stdio (`shared.go:631`).
- `IOTransport{Reader, Writer}`, `NewInMemoryTransports()` (`transport.go:149,183`); client `NewClient`, `Connect`,
  `ListTools`, `CallTool`, `StreamableClientTransport{Endpoint, HTTPClient, DisableStandaloneSSE}`.
- **DNS-rebinding guard:** by default a request arriving from 127.0.0.1/::1 with a non-localhost `Host` is 403. That
  is exactly a reverse proxy on the same host. `/mcp` sets `DisableLocalhostProtection: true`: the guard protects
  unauthenticated local servers from a rebinding browser, and every `/mcp` request here needs a bearer token, which
  such a browser can neither read nor send; the session cookie, the one credential a browser carries
  automatically, is stripped before authentication (Task 2).

```go
// PlanHash is the hex sha256 of the canonical JSON of cs as [{op, kind, name, fields}], in order; Value is left
// out. Two plans with the same changes have the same hash.
func PlanHash(cs []Change) string

// PlanMismatchError is ApplyPlanned's answer when the store no longer plans to wantHash: nothing was applied.
type PlanMismatchError struct {
    Changes []Change // the fresh plan
    Hash    string   // PlanHash(Changes)
}

// ApplyPlanned is Apply with a guard: when wantHash is not "", the plan is made inside the apply's Batch (the
// store is write-locked from then until commit) and, if its PlanHash differs, nothing is written and the error is
// a *PlanMismatchError. Apply(ctx, want, sec, prune) is ApplyPlanned(ctx, want, sec, prune, "").
func (s *Service) ApplyPlanned(ctx context.Context, want File, sec Secrets, prune bool, wantHash string) ([]Change, error)
```
