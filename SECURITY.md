# Security policy

## Reporting a vulnerability

Report a vulnerability through GitHub private vulnerability reporting:
<https://github.com/47vigen/remora/security/advisories/new>.

Never open a public issue for a vulnerability.

## Supported versions

The latest minor release receives security fixes.

## Scope

In scope: remora's own code and the way remora configures the engines it ships.

A bug in an engine itself belongs to that engine's project. Report it there:

- Bifrost: <https://github.com/maximhq/bifrost/security>
- CLIProxyAPI: <https://github.com/router-for-me/CLIProxyAPI/security>
